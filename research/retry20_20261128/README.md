# Conditional second pouring cycle: research bundle

This experiment targets 20 mL within +/-0.5 mL and 24 raw physical seconds, including return to the original pregrasp position and 12 stable frames. Peak spill across all particle labels must not exceed 1 particle. A further 2 seconds of observation checks for late water. The earlier +/-1 mL and original +/-0.020 mL criteria remain separate secondary results. See [the actual selected report](../../results/retry20_20261128.json).

The first approach is fixed at 84.0 degrees. A second approach at 84.1 degrees is permitted only when the actual settled volume is below 19.5 mL, current peak spill is at most 1 particle, and a conservative motion budget leaves time to return and stabilize at home. The decision event records intent; the second `response_cycle_start` and measured endpoint record actual execution. A complete cycle includes approach drainage, cutoff and quiet measurement: the second micro action can be skipped while retaining the water already released during approach.
