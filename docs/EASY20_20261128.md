# 固定20mL入门课程：±1mL

2026-11-28完成20次实时液体仿真：6次训练标定、4次验证、10次独立成对测试。这个独立入门任务采用20mL±1mL、24原始物理秒、最多全标签峰值洒1粒；原20–40mL、±0.1%任务的要求和失败记录保持不变。

候选和基准最终是**同一组参数**。验证平局保留基准；这不是训练出了精度提升。五个新初态的实际水量为19.289340、19.092510、19.309023、19.269657、19.269657mL，两组结果相同。每次均返回原预握位置并满足12帧稳定，额外2秒观察没有晚滴。原严格±0.020mL标准两组均为0/5。

方法是一个参数的有限标定，不是神经网络或PPO：仅比较内部停止偏置0、+0.5、+1.0mL，其他动作速度、实际目标、粒子质量与求解器不变。每个条件都重新运行真实PBF。训练选候选，验证选推荐；两份参数及推荐均在测试前冻结，测试不调参。

两个训练初态中，0和+0.5mL都在90.209707°回倾，结果完全相同；+1mL在90.636374°回倾，相差一个60Hz控制帧，最终出水增加约1.54mL。这是本轮观察到的非线性响应，不能直接用参数线性插值推断水量，也不能据此声称所有小动作都存在同一最小出水量。

难点更集中在余流、液面波动和细量控制。当前路线与回位可完成，但采用运动学预握，尚未验证实际摩擦抓握、力矩或真机能力。水量来自固定身份粒子的空间分区与质量，属于仿真真值，并非机械臂腕力称重。粒距2.7mm、单粒0.019683mL、11625总粒子/2880源粒子保持不变。
