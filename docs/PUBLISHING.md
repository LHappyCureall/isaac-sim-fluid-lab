## 每日提交流程

1. 确认 remote 是自己的 `LHappyCureall/isaac-sim-fluid-lab`，读取远端变更；遇到冲突时保留双方修改并报告。
2. 同步已允许的自写文件，更新当日实际完成的学习记录。
3. 运行 `python tools/check_release.py`，检查 diff。物理逻辑变更还需运行相应 Isaac Sim 验证，不能用旧结果声称新代码已验证。
4. 只有实际变更才创建说明明确的提交，正常推送；不强推，不制造空提交。
5. 新增未列入清单的文件、来源不明资源或不能确认已完成的实验，先留在本地待核对。

每日自动化需要本机开机且桌面应用保持运行，并能访问工作目录和 GitHub；参见 [OpenAI 官方定时任务说明](https://learn.chatgpt.com/docs/automations?surface=app)。没有变更时保持安静；提交成功或遇到新的阻塞时提供简短结果。
