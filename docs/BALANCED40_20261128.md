# 40mL首轮组合：水量更准，仍有一例洒水

2026-11-28完成9次已见案例标定、4次新初态验证和20次独立配对测试，共33次实时PBF执行。固定粗倒24.8°/秒，只比较首轮87.0/87.05/87.10°；补水87.2°、其他速度、落稳测量及物理保持不变。20/30mL与之前两轮研究版本均保留。

三个已见初态覆盖旧过量、旧洒水和上轮欠量。87.05/87.10°均3/3通过，按预声明的可行组平均物理时间选择更快的87.10°；先冻结，再完成两组新初态验证，才冻结最终策略并测试十组全新初态。上轮测试198403在本轮明确属于已见开发，不能再次算独立测试；本轮新测试不调参或重选。

水量更接近目标：9/10配对绝对误差更小，1/10更大；全部10例的物理动作均略慢。联合通过率没有增加，尚未全部达标。199308两组分别收到39.621879/40.389516mL，水量合格，却均洒2粒而失败。只读原始轨迹显示，2.966667秒的anchor_hold阶段已有2粒洒出，首轮接近角动作3.216667秒才开始；干预前的真实物理前缀相同。因此改后面的首角无法消除已经发生的peak洒水，不能继续只搜角度或忽略该例。这里记录的是洒水分类时间，不据此推断粒子喷出时刻或具体成因。

33例原始证据已独立审计，数值、质量、实际关节与姿态、完整回位、晚滴检查、两次冻结顺序及58项历史保护均通过；三组旧首循环与18组干预前对照均一致。记录和物理有效性通过，不等于所有任务通过。

已见旧过量例最终40.173003mL，旧欠量例由39.464415变为40.113954mL，均通过±0.5mL；这些复访单列，不混入十个新初态的成绩。原严格±0.04mL两组仍0/10。当前方法是有限参数标定与真实落稳反馈，不是CEM/PPO或神经网络策略，也不证明任意20–40mL、任意初态或真实硬件精度。

最新研究实现为本机`projects/pour_policy_balanced40/balanced_control.py`，SDK批量入口`run_balanced_test.py`；冻结配置选`first_8710`，即首轮87.1°、粗倒24.8°/秒、重试87.2°。控制器无参数默认值仍用于实验基准，不能误当作已选候选。精选[数据](../results/balanced40_20261128.json)、[结果图](../results/balanced40_20261128/balanced40_results.png)及[源码与两份冻结JSON](../research/balanced40_20261128/README.md)独立版本化。
