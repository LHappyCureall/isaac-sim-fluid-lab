# 40mL粗倒减速：修复一例洒水，新增欠量失败

2026-11-28独立完成6次已见初态标定、4次新初态验证及20次全新配对测试。只比较粗倒速度25.6/25.2/24.8°/秒；首轮87.0°、条件补水87.2°、其余动作和物理固定。基准是[上一轮首角优化版](FIRST40_20261128.md)，不是87.1°原版；20/30mL与旧模型保持原SHA。

24.8°/秒在两个已见初态中均通过：原过量例最终39.720294mL，原洒水例39.700611mL，均零洒出；25.2°/秒有39.444732mL欠量，不能因零洒水入选。选定24.8°/秒后先冻结，再通过两组新初态验证，才冻结最终策略并执行十组独立配对测试。测试不调参，也不据其结果切换模型。此为有限参数标定，不是CEM、PPO或神经策略训练。

原组198404收到40.035222mL但洒2粒；候选在同初态收到39.818709mL、零洒出，修复该例。候选另在198403收到39.464415mL，欠0.535585mL而失败，不能四舍五入成±0.5mL成功。此时实际落稳后剩余11.283秒，原保守完整二次补水与回位预算为13.858秒，因此如实拒绝重试；不删时间保护或加长24秒来挽救结果。最多洒1粒也不能抵消欠量。

因此本轮没有提升独立测试联合成功率，MAE反而增大：候选在9/10配对中绝对误差更大、1/10相同，没有一对误差更小。不能称为全部调好或更新默认。原严格±0.04mL分别仅2/10、0/10，仍单列。原过量例40.527297mL已被局部优化修复，但新初态揭示了欠量边界，不能据已见测试重新调角后继续冒称独立验收。
